# bm

Operational glue for the BinauralMeet workspace: dev/test scripts and
cross-repo documentation for [binaural-meet](https://github.com/BinauralMeet/binaural-meet)
(client) and [bmMediasoupServer](https://github.com/BinauralMeet/bmMediasoupServer)
(signaling/mediasoup server), which are checked out as sibling directories here
but are separate git repositories in their own right (not submodules — see
`.gitignore`).

Start at the docs index:

```sh
docs/bin/doc
```

That prints how to look things up plus a generated index of every topic
(workspace layout, dev-environment/sandbox notes, architecture rules). See
`docs/README.md` for the conventions this tree follows.
